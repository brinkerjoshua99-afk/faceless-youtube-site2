# Faceless YouTube Content OS — Landing Page

A one-page sales site for the **Faceless YouTube Content Operating System**, a 17-page digital workbook that helps creators go from channel idea to published video with a repeatable faceless YouTube workflow.

## About

This site is the landing page for the product, sold through [Whop](https://whop.com/stopscroll/the-faceless-youtube-content-operating-system/). It includes:

- Product overview and feature breakdown
- FAQ section
- "Buy on Whop" checkout buttons
- Whop Pixel installed for ad conversion tracking

## Hosting

Deployed on [Netlify](https://netlify.com), connected to this GitHub repo — any commit to the main branch triggers an automatic redeploy.

- `index.html` — the full landing page (single-file site)
